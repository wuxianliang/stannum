# Loop Orchestrate: STN3 tool layer — execute the 24-step plan

- Goal: execute every step of `docs/plans/stn3-tool-layer-execution-2026-09-30.md`
  (24 steps, 7 phases) to a checked-off state — each step: one orchestrate run
  implements it → controller verifies (re-run gate) → oracle review (design doc
  + changed files in selection, P0/P1 triage) → repair rounds if needed →
  commit (step files only) → plan checkbox `- [x]` + SHA (separate commit) —
  until all steps complete or a stop condition fires.
- Normative spec: `docs/designs/stn3-tool-layer-2026-09-29.md` (f4bc1e3
  reviewed revision). Plan vs design conflict ⇒ design wins, plan gets fixed.
- Frozen check: each step's "Done when" + phase gates. Levels: L1/L2 command
  gates (cargo test / pytest / CI green — controller re-runs when possible);
  L4 oracle review per step (ask_oracle mode=review, P0/P1 triage).
- Scope: stannum repo — Phase 0/2+ on branch `stn3` (base upstream/main@d57ef58);
  Phase 1 (WS0) on `main` lineage 24f5c02; pgembed repo
  (`/Users/wxl/Projects/pgembed`) checkpoint steps only: bump
  `STANNUM_COMMIT` in `pgbuild/Makefile` + commit there; plan-doc checkbox
  edits.
- Out of scope / never edit: `contract/expected/**` (except the pinned
  recording job itself), released `postgres/sql/stannum--*--*.sql`,
  weakening any gate, `contract/` check, or CI assertion. [pg-agent] steps
  skipped until 6.4 (repo at ~/Projects/pg-agent, outside workspace).
- Stop states: success (all steps checked); blocked (2 repair rounds red,
  representation cannot supply df_agg/norms/bound, any need to touch
  never-edit files, design §3 seam deviation); stalled (2 stagnant turns);
  exhausted (turn budget).
- Brakes: max 40 orchestrate attempts total; 2 failed repair rounds on one
  step ⇒ stop + escalate with failing evidence.
- Irreversible-action gate: origin pushes (branch + phase ends) pre-authorized
  by the loop protocol; pgembed commits pre-authorized at checkpoint steps.
  Anything else destructive ⇒ ask_user first.
- Commit style: English imperative one-line title, body = motivation, trailer
  `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`; commit scope =
  that step's files only; checkbox change committed separately.
- Session cadence: brief every orchestrate run with step number + design §refs;
  runs never commit (controller commits after verify+review).
